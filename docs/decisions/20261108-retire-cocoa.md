# #14｜全家共用食材庫移除可可粉

2026-11-08，Bebe 明確決定全家移除 `cocoa_powder`，並同意料理配方調整及各裝置備份後停用舊資料。

- 官方 `ingredients.json` 移除指定 ID，現行有效基準為 100 項；先前 99／101 項的 SHA-256 核准仍保留供歷史驗證與回復，不代表現行清單。
- 優格碗移除可選配料及 Bebe 3 g／Jason 5 g／Ariel 3 g 的可可粉份量；飲品吧移除可選配料。歷史餐點營養快照不重算。
- 已驗證家庭權限的裝置，在 Personal Kitchen State 載入後、去重／custom 合併前，先用既有照片備份機制建立完整可回復 journal，再停用主快取與 custom 中的指定 canonical ID。備份／寫入失敗回復，登入切換或並行修改則停止。未登入不執行停用。
- 保留 `kitchen_v2_fk14_retire_cocoa_20261108` 的原始備份及 IndexedDB 照片；不清空裝置，不刪除 household／ariel 庫存、採買、家用品或歷史餐點，不依同名刪除其他私人 ID。
- 舊本機料理快取原文保留；目前料理檢視停用可可粉引用，編輯仍連到原有儲存路徑。未來儲存料理時使用目前有效配方。
- 雪白菇缺少獨立處理：household 的 99／100、只有指定缺少且無其他差異時，真實點擊檢查才詢問備份修復。未知同名／品牌衝突停止，不再補回可可粉。
- 這是指定 ID 的明確退休決定，不是一般「手機刪食材即刪全家母庫」政策；手機其他刪除行為仍需另行設計。
- 正式 Supabase 唯讀核查共用修正 0 筆、可可粉 0 筆，無需資料庫刪除。無 schema／RLS／同步政策變更。
- 程式／母庫可由 Git 復原；手機資料需用該機 journal／照片備份回復，不能把 Git revert 視為手機已還原。

部署與實機驗收證據記於 [Issue #14](https://github.com/leebebe1002/kitchen-app/issues/14)。
