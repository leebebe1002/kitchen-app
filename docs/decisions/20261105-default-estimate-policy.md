# #21｜官方估算預設與產品標示覆寫

日期：2026-11-05。狀態：本機候選；未 Push／部署／變更正式資料。

## 已核准產品規則

一般食材若能依 TFDA、必要時 USDA 找到生熟、可食部、類型相符的完整五項營養，預設顯示「官方資料庫估算」而不要求填品牌與包裝；產品有本人核實的實際標示時，僅覆寫對應商品，來源與快照跟隨本機 custom ingredient。缺資料、加工產品配方或每顆重量不明則待確認，絕不以 0 或不相干產品代替。

- 希臘優格預設全脂原味無額外加糖；以 USDA SR Legacy 171304 每 100 g 可食部 97 kcal 作代表（非品牌標示）。
- 雞腿預設生、去骨含皮；USDA SR Legacy 172385 221 kcal／100 g。
- 蝦仁、板豆腐、芒果、里肌火鍋牛片及梅花豬肉用已有 TFDA 原始稽核樣本之可食部代表值，保留類型差異說明；綜合生菜依 USDA 生綠葉萵苣近似。
- 香蕉改去皮 g 秤重；不猜每根重量。培根與貝果改 g 秤量，但因缺每 100 g 的可靠來源，原每條／每個數字停用、待補。
- 生鴻喜菇與雪白菇分開（後者新 ID）；原鴻喜菇／雪白菇 ID 保留給鴻喜菇並維持引用；不複製未知品牌營養。
- 原味貝果已轉成 g，採 USDA SR Legacy 174899 每百克代表值；不能把未核對重量的「個」直接換算。松露橄欖油僅在近似純油、未加其他大量調料的條件下採 USDA SR Legacy 171413，否則仍需商品標示。
- 糙米飯沿用 \`brown_rice\` ID，只改名稱為糙米飯並依 USDA 熟重估算；熟白飯新建 \`white_rice\`。不搬移、不改舊料理、庫存及飲食紀錄的引用。
- 王子麵預設乾麵**不含調味包**；無對應麵體完整營養時保持 null 待確認，不沿用 100/10/5/10 佔位。蝦仁漿佔位亦停用。
- 皮蛋、貢丸、蛋餃、馬鈴薯泡麵等保持顆／包數量，缺可信單位重量／標示不參與精算。
- UI 預設只顯示來源與適用條件，產品標示核實欄位摺疊；OCR 取得標示會自動展開，尚缺值不能核實。

## 範圍、相容、安全與回復

從 99 項官方食材增加 2 項至 101 項，舊的 99 項獨立驗收基準仍保留原 SHA-256 白名單，新增 101 項候選另列白名單；測試同時驗兩版，不取消先前備份／照片／使用者核實守門。官方 \`src/data/ingredients.json\` 與來源索引一同版本化，舊改過營養或經核實的產品標示優先，未編輯舊 cache 依完整快照合併新版，未知舊值不自動證實。相同名稱但不同 ID 的私房食材不得因新增官方項目或既有官方項目改名而被清理；遇到改名衝突，保留舊官方顯示名與私房食材，待本人自行區分，不自動認證舊營養；測試保護此情境與既有 references。

本輪**沒有**變更 Supabase schema、RLS、Storage、登入／同步成員、Personal Kitchen State 的資料邊界或合併政策，也不清除 localStorage。household／ariel／未登入都僅使用隔離假資料測試。所有 Base64 圖片仍依原有儲存保護。PRD／DATA_SCHEMA／DESIGN_SYSTEM 中存在舊架構陳述，本輪不自行更改。

若需回復候選，尚未部署可捨棄工作分支；部署後需明確發布授權使用一般 revert 並重新部署，而非 force push。使用者已經在裝置另行修改或核實的資料不會因 Git revert 自動回復，須先備份、核實 Scope 再個別處理。

## 估算限制

官方參考樣本不是實物營養標示。米飯水分、肉類部位油花與含皮比例、產品配方及秤量狀態都會造成變動；來源待確認不等於數值一定錯。完整逐項現況在 \`docs/audits/nutrition-2026-11-05.json\`，保留既有 89 項與 99 項歷史稽核。
